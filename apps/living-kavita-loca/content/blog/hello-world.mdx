Welcome to my blog! This is my first post written in MDX, which means I can use both **Markdown** and React components together.

## Why MDX?

MDX is a powerful format that combines the simplicity of Markdown with the power of React components. Here are some reasons I love it:

- **Easy to write** - Just like regular Markdown
- **Component support** - Embed interactive React components
- **Syntax highlighting** - Code blocks look great
- **Type safety** - Full TypeScript support
