# .scratchwork

This directory is **not committed to git** and is safe for storing temporary work.

## Purpose

Use this folder to save:

- Work-in-progress (WIP) code
- Notes and thoughts
- Experimental files
- Temporary scripts
- Any other content you want to keep locally but not commit to the repository

## What happens here

- ✅ Files are **saved locally** on your machine
- ❌ Files are **not tracked by git**
- ❌ Files **will not be committed** or pushed to the remote repository

## Ideal for

- Quick experiments without cluttering your git history
- Personal notes about the project
- Draft implementations before moving them to the main codebase
- Debugging files and test data

Feel free to use this space however you like—it's your local scratchpad!
